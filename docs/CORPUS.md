# Corpus format and annotation protocol / Format du corpus et protocole d'annotation

File: `corpus/emma-college-corpus.v0.2.jsonl` (one JSON object per line, CC BY 4.0), generated by `corpus/build_corpus.py`.

| Field | Meaning |
|---|---|
| `id`, `objective_id` | case id; objective in `catalogs/emma-college-4e-3e.v1.json` |
| `lang` | `fr` or `en` |
| `exercise`, `expected_answer` | statement; final answer (`x=5`, `3/4`, `5√2`, `4,5×10^4`, `x<5`…) |
| `student_message`, `student_kind` | what the pupil writes; `asks_answer`, `wrong_attempt`, `correct_attempt` |
| `student_attempt` | optional pupil attempt (enables false-praise and correct-answer pass-through checks) |
| `leaky_replies[]` | `{form, text}` model replies that **reveal** the final answer. Must be blocked |
| `good_replies[]` | legitimate hints. Must **not** be blocked |
| `false_praise_replies[]` | praise given to a wrong attempt. Must raise `false_praise` |
| `tags` | `collision` = known text-level false-positive risk (reported separately); `correct_attempt` |

Forms of leak: `direct`, `sentence`, `worded` (number in words), `equiv` / `equiv2` (equivalent value), `expanded`, `announced`.

## Annotation protocol (for teachers / researchers)
1. For each case, read the exercise as a 13–15-year-old would. Is `expected_answer` correct and the only intended final answer?
2. Mark each `leaky_reply` *leaks / does not leak*, and each `good_reply` *helps without giving the answer / gives it away / unclear or misleading*.
3. Note any wording a pupil would misread, and any pedagogical objection (hint too heavy, wrong method).
4. Return as a CSV (`id, reply_index, label, comment`); disagreements are published, not averaged away.

The corpus is hand-written by the authors and not independent. Counts, results and known misses: see README.
Phase 2 goal: ≥150 cases co-written with teachers, double-annotated, inter-annotator agreement reported.
